# Assignment_Mapping-a-Pattern-onto-a-Curved-Surface

# Approach
**This approach maps a pattern realistically onto a flag by warping it to the flag's perspective, extracting fold deformation using image gradients, and simulating soft shading based on luminance. A soft alpha mask ensures smooth edge blending. The pattern is then blended using a multiply mode to embed it naturally into the fabric texture. Finally, alpha blending merges the result with the original flag, preserving lighting and surface detail for a photorealistic composite.**
